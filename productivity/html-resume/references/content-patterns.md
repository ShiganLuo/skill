# Resume Content Patterns

## Skills Section: Capabilities, Not Experiences

Skills describe **what you can do**, not what you did.

Bad:  "XGBoost 优化 MSI 检测（99→12 特征，AUC ≥ 0.855）"
Good: "XGBoost / LightGBM 分类与集成学习；特征选择、交叉验证、模型可解释性"

Pattern: ability type → tools/methods → application context.
Save concrete numbers for the experience section.

## Summary: Narrative Arc

Structure in 3 beats:

1. **Identity** — who + research focus (one sentence)
2. **Competency chain** — headline results with numbers, NOT all details
3. **Differentiator** — what makes you unique (ML + full-stack, etc.)

Bad:  compresses every experience bullet into one paragraph.
Good: tells a story with just the headline numbers.

## Interests: Bare Noun List

Good: "开源社区；足球；篮球与健身"
Bad:  "积极参与开源社区交流协作；院足球队成员" — reads like work experience.

## Education Format

Chinese: `School — Program Name（Degree Type）`
English: `School — Program Name (Degree Type)`

Examples:
- 南开大学 — 生物技术与工程（生物与医药工程硕士）
- Nankai University — Biotechnology & Engineering (M.Eng. in Biopharmaceutical Engineering)
- 南昌大学 — 数据科学与大数据技术（工学学士）
- Nanchang University — Data Science & Big Data Technology (B.Eng.)

## Two-Language Sync Checklist

When changing one language, check:
- [ ] Education program names and degree types
- [ ] Skills: same categories, equivalent descriptions
- [ ] Summary: same narrative structure (not word-for-word)
- [ ] Project dates and descriptions
- [ ] CSS: English ~0.5pt smaller, tighter padding/margins
