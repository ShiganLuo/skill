# generate_meta_input.py - Unified Meta Input + Design Generation

## File Location
`workflow/Omics/src/download/generate_meta_input.py`

## Single Unified Interface (no subcommands)

```bash
python generate_meta_input.py \
    -g gsm_metadata.csv \
    -i sra_metadata.csv \
    -d fastq/ \
    -o meta_input.tsv
```

**CLI args:**
- `-g`: gsm_metadata.csv path
- `-i`: sra_metadata.csv path
- `-d`: fastq directory
- `-o`: output TSV path

**Output columns:** `sample_id`, `data_id`, `fastq_1`, `fastq_2`, `design`

## Design Logic

1. Merge `gsm_metadata.csv` (column `SRA` = SRX) with `sra_metadata.csv` (column `SRX`)
2. Auto-detect design columns: all columns in gsm_metadata **except** identifiers (`GSM`, `GSE`, `SRA`, `BioSample`)
3. For each row, take non-null values from all design columns, join with `_` -> group name
4. If all design columns are empty -> `unclassified`
5. Within each group, assign `.repN` suffix by GSM occurrence order
6. Technical replicates (same GSM, multiple SRRs) share the same rep number

## Multi-column Example (4RNAseq)

gsm_metadata columns: `GSM, cell type, patient age, GSE, SRA, BioSample, tissue, phenotype, treatment, disease state`
Auto-detected design cols: `cell type, patient age, tissue, phenotype, treatment, disease state`

Non-empty values from all 6 design columns are joined with `_`. Rows with all empty -> `unclassified.repN`.

Technical reps: GSM4110157 has 2 SRRs (SRR10239201, SRR10239202) -> both get `ovarian granulosa cells_normal.rep1`.

## gsm_metadata.csv Structure

Columns vary per project (GEO doesn't enforce a fixed schema). Common columns:
- `GSM` - GEO Sample accession (always present)
- `SRA` - SRA Experiment accession (SRX, always present, used for merge)
- `GSE` - GEO Series accession
- `BioSample` - BioSample accession
- Variable metadata columns: `cell line`, `cell type`, `treatment`, `tissue`, `phenotype`, `disease state`, `patient age`, etc.

All non-identifier columns are automatically included in the design. No need to specify which columns to use.

## sra_metadata.csv Structure

Fixed columns (generated by GSE_runinfo.py):
`SRX, Sample_id, Organism, Name, Instrument, Strategy, Source, Selection, Layout, Construction protocol, Data_id, spots, bases, size, published`

- `Sample_id` = GSM accession (links back to gsm_metadata)
- `Data_id` = SRR accession (the actual sequencing run to download)
- `SRX` = SRA Experiment accession (links to gsm_metadata's `SRA` column)

## Design Decision History

- Originally had two subcommands (`design` + `meta_input`) with user-specified `-c` column selection
- User requested simplification: "全部拼接在一起吧, 不需要区分子命令, 直接在generate_meta_input基础上生成"
- Now: single function, auto-detect all non-ID columns, no column selection needed
